## Spot it
Work starts from a feature name ("add the export", "brainstorm the integration") and the
goal changes midway: reverts, "plan changed", "remove it completely", topic hops at night.

## Proof it is installed
Opening prompts carry the outcome, the person served and a done-when, without a nudge.

## Why it matters
An unstated outcome is decided by whatever is easiest to build next. One line up front
keeps the agent and the user pointed at the same finish line.
